- **Multi‑Motor Avanzado**: Analiza archivos y hashes simultáneamente con más de 70 motores de detección, ofreciendo una cobertura completa sin exponer tu actividad en la nube pública.

## Preguntas Frecuentes

**¿Es compatible con Windows 7 o Windows 8?**
No. PrivScanner Suite Pro requiere Windows 10 (versión 1809 o superior) o Windows 11. No se ofrece soporte para versiones anteriores de Windows.

**¿Necesito una conexión a internet para usar la herramienta?**
Sí. La conexión a internet es necesaria para descargar y actualizar los motores de análisis, así como para consultar las bases de datos de reputación de hashes y URLs en tiempo real.

**¿Los archivos se suben a servidores externos?**
Los archivos se procesan a través de las API oficiales de los motores de análisis, siguiendo los protocolos establecidos por cada proveedor. No se almacenan en ningún servidor propio ni se comparten con terceros.

**¿Puedo ejecutar PrivScanner Suite Pro sin permisos de administrador?**
La instalación requiere privilegios de administrador. Sin embargo, una vez instalado, el análisis de archivos puede ejecutarse con permisos de usuario estándar.

**¿Cuántos motores de antivirus están disponibles?**
PrivScanner Suite Pro ofrece acceso a más de 70 motores de análisis. La cantidad exacta puede variar según la disponibilidad de cada proveedor en el momento del escaneo.
